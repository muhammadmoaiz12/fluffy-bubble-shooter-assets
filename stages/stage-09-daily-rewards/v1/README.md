## Preserved decisions

Optional daily gifts, one validated daily challenge, and accessible weekly missions support the solo adventure. Streak milestones are non-punitive examples; comeback eligibility and all amounts/timing remain configurable. The calendar uses Coins and existing boosters/gift imagery. Stars, energy, gems, keys and tickets appear only in the reusable catalog with their existing restrictions; no new daily grant or paid gate is approved. Pending and Claimed remain distinct.

## Integration notes

Static asset compositions, not a working reward system. Runtime should draw localized labels, reward counts, day labels, goals and actual progress from validated data. The supplied labelled buttons and partial progress are previews. Verify hit areas, nine-slice borders, reset policy and exactly-once claims in the game. No character pixels were redrawn; only resizing/compositing was used. PNG/WebP exports are 128/256/512. Original master links avoid duplicating existing art.
