# Moonlight Cannon · Five visual upgrade tiers

83 masters, 498 PNG/lossless WebP exports. Eight views per tier, individual state illustrations, shot-effect variants and app icons.

![Five tiers](evolution.jpg)

## Identity and source priority

Tier 1 view files are byte-for-byte copies of the existing approved cannon. Tiers 2–5 are new AI-generated upgrade interpretations using the original cannon identity and reviewed tier heroes as references. Existing cannon and locked character files are untouched. Original source boards are preserved in `references/` with SHA-256 hashes. 

## Integration limits

These are visual tiers, not newly approved purchase costs, damage values, unlocks or gameplay mechanics. Existing GDD physics and balance remain authoritative. Boards show differing growth percentages; no automatic gameplay scale or hitbox change is prescribed. Upgraded view masters are normalized to a 1024 canvas with an 880px maximum width, 850px maximum height and bottom baseline y=922. Original Tier 1 files retain their existing dimensions and bytes. Effects/components may use the same export envelope; use recorded bounds for placement. Transparent PNG and lossless WebP exports are 128/256/512px maximum dimensions.

Idle, aim, charge, fire and shine are separately saved illustrations. Charge/shine overlays preserve the hero underneath; firing is an illustrative composition with reusable effects, not a muzzle-calibrated engine animation or 3D rig. Individual generated angles can still have geometric differences. Review rotational continuity, muzzle positions and transitions in-game before production lock. Material swatches and close-ups remain reference-board details rather than invented texture maps.
